# /import

Read docs/replace-re-leased.md. Map properties and units first. Run `npm run property -- import re-leased --file=imports/tenancy-schedule.csv --dry-run`. Supply --map, --currency or --date-format when needed. Compare the results with the source, then repeat without --dry-run. Imported leases remain proposed until dates, status and signed evidence are verified. Preserve the source export privately.
