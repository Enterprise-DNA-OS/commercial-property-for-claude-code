# Why the database is the product

A commercial manager needs a rent roll, renewal dates, overdue balances and the evidence behind them. This base keeps those records in one database. A coding agent runs the same CLI as a person and follows the recipes in .claude/commands.

A conventional screen gives mobile access, offline inspection capture, drag and drop scheduling and role-specific portals. This base supplies none of those. Its HTML files are read-only reports and draft paperwork. They do not edit records or run a server. Enterprise DNA can build the required screens and connections into a scoped version.

PGlite is a local single-process store. PostgreSQL supports a managed shared deployment. Row security is enabled without public policies, so staff roles see no records until explicit permissions are designed. The owner connection is for controlled operation. Authentication, roles, backup recovery, monitoring and external accounting reconciliation need deployment work before a team relies on it.
